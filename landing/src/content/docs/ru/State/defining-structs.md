`#[amethystate]` создаёт сохраняемое состояние на основе структуры Rust.
Здесь описаны расположение структуры, её история версий и вложенные компоненты.

Соседние страницы разбирают:

- [Атрибуты полей](/amethystate/ru/state/fields/) — пути, defaults и кодирование;
- [Нечитаемые значения](/amethystate/ru/state/unreadable-values/) — ошибки чтения и удалённые ключи;
- [Правила](/amethystate/ru/state/rules/) — нормализацию значений;
- [Собственное открытие](/amethystate/ru/state/opening-structs/) — `open = manual` и проверки нескольких полей;
- [Serde](/amethystate/ru/state/serde/) — атрибуты объявлений и листовых значений.

## Атрибуты структуры

```rust
#[amethystate(prefix = "network", version = 1, mode = "reactive")]
pub struct NetworkState { ... }
```

| Атрибут | Тип | Описание |
| --- | --- | --- |
| `prefix` | `String` | Базовый путь полей. Самостоятельной структуре нужен `prefix` или `as_root`. |
| `version` | `u32` | Версия схемы для миграций; по умолчанию `0`. |
| `id` | `String` | Различает независимые истории версий на одном префиксе. |
| `rename_all` | `&str` | Стиль имён полей в store: `lowercase`, `UPPERCASE`, `PascalCase`, `camelCase`, `snake_case`, `SCREAMING_SNAKE_CASE`, `kebab-case` или `SCREAMING-KEBAB-CASE`. Не меняет явные `path`. Другие значения — ошибка компиляции. |
| `mode` | `String` | По умолчанию `"reactive"`: доступ через хендлы. `"persistent"`: явная загрузка и сохранение обычных полей. См. [Persistent-only](/amethystate/ru/getting-started/quick-start/#режим-persistent-only). |
| `as_root` | флаг | Поля непосредственно в корне. Не совмещается с `prefix`. |
| `on_unreadable` | вариант | Политика ошибки чтения: `Refuse` по умолчанию или `UseDefault`. |
| `on_delete` | вариант | Политика удалённого ключа поля: `Keep` по умолчанию или `UseDefault`. |
| `unreadable_entries` | вариант | Чтение записей карты: `Refuse` по умолчанию или `Skip`. Только для карт. |
| `open` | `manual` | Собственная реализация `Open`; конструкторы для глобального store не создаются. |

`rule` задаётся на поле, не на структуре. Для проверок нескольких полей
используйте собственную реализацию `Open`.

Без `prefix` и `as_root` структура становится компонентом для встраивания
через `nested`: расположение задаёт родитель.

## Места и линии

Структура занимает пути полей, а не весь `prefix`. Две структуры могут делить
префикс, если их поля не пересекаются. Карта занимает всё поддерево, поскольку
ключи её записей заранее неизвестны. Подробнее —
[Владение путями](/amethystate/ru/concepts/claims/).

История версий не равна владению путями. **Линию** определяют префикс
и необязательный `id`. Структуры без `id` относятся к безымянной линии
префикса. Если независимые структуры делят префикс, задайте явный `id`
всем, кроме максимум одной:

```rust
#[amethystate(prefix = "ui", id = "panels", version = 3)]
pub struct Panels { ... }
```

Два объявления одной линии с одной версией вызывают
`MigrationError::DeclaredTwice`. Разные линии с пересекающимися путями вызывают
`MigrationError::ClaimedTwice`: `id` не разрешает пересечение данных.

Сохраняйте выпущенный `id` неизменным. Новый `id` начинает другую историю,
а запись прежней линии остаётся как дрейф.

## Вложенные структуры

Компонент без собственного префикса встраивается в родителя через `nested`.
Его поля располагаются под префиксом родителя и именем вложенного поля:

```rust
#[amethystate]
pub struct DatabaseConfig {
    #[amestate(default = "localhost".to_string())]
    pub host: String,
}

#[amethystate(prefix = "sys")]
pub struct SystemSettings {
    #[amestate(nested)]
    pub db: DatabaseConfig, // stored as "sys.db.host"
}
```

Чтобы исключить имя вложенного поля из пути хранения, используйте
[`flatten`](/amethystate/ru/state/fields/#поле-чьи-пути-лежат-на-уровне-хозяина).

## Как разделить одно место между двумя структурами

Не объявляйте одно сохранённое значение дважды. Передавайте компонентам
клоны существующего хендла поля или `ReactiveCell`, созданную на его основе.

`Kv` предназначен для незанятых путей и не обходит проверку владения.
См. [Владение путями](/amethystate/ru/concepts/claims/).

## Хранение на уровне корня (`as_root`)

С `as_root` поля сохраняются непосредственно в корне, без общего префикса:

```rust
#[amethystate(mode = "persistent", as_root)]
pub struct AppConfig {
    #[amestate(default = "acme".to_string())]
    pub name: String,

    #[amestate(default = false)]
    pub verbose: bool,
}
```

Например, TOML-файл содержит:

```toml
name = "acme"
verbose = false
```

Такой вид удобен, если другая программа ожидает ключи верхнего уровня или
конфигурацию редактируют вручную. Корневые поля тоже занимают свои пути:
две структуры не могут объявить один ключ. См.
[Владение путями](/amethystate/ru/concepts/claims/).
