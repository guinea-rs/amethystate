Дрейф схемы — расхождение сохранённых объявлений с кодом при неизменной версии.
Например, поле перенесли или значение заменили картой, но шаг миграции не задали.

## Что с чем сравнивают

При совпадении сохранённой и объявленной версий движок сравнивает занятые пути.
**Место** — сохранённый лист или уровень карты, а не вложенная обёртка.
Добавление или удаление сегмента обёртки поэтому определяется как перенос
её дочерних полей:

```text
  объявлено                   принадлежит
  ------------------------------------------------
  ui            вложенная     -           сама она местом не является
    theme       поле          ui.theme

  ui            flattened     -           и сегмента детям не даёт
    theme       поле          theme
```

Сравниваются пути, не имена полей Rust. Вложенное поле `ui.theme`
и `path = "ui.theme"` могут задавать одно расположение. Одинаковые имена полей
под разными префиксами, наоборот, задают разные расположения.

## Приговоры

| Изменение | Оценка | Значение |
| --- | --- | --- |
| Прежний объявленный путь удалён | **ломающее** | Старые данные больше не описаны объявлением. |
| Лист стал уровнем карты или наоборот | **ломающее** | Формы хранения различаются. |
| Объявлен новый путь | **зависит от данных** | Пустой путь безопасен; существующие необъявленные данные нужно проверить. |
| Изменилась необязательность | **безопасное** | Путь по-прежнему принадлежит объявлению. |

Ломающее отличие создаёт отчёт о дрейфе. Остальные изменения включаются
для контекста, даже если сами по себе безопасны.

Переименование выглядит как удалённый и добавленный пути. Чтобы зафиксировать
связь между ними, используйте
[`#[rename(old => new)]`](/amethystate/ru/migrations/defining-steps/) в миграции.

## Запуск он не блокирует, но и сам не проходит

Сам отчёт о дрейфе не блокирует открытие. Прежняя записанная схема сохраняется,
поэтому расхождение повторно сообщается на следующих открытиях до исправления.

Если изменение задумано, поднимите версию и напишите миграцию. Если нет —
восстановите прежнюю раскладку. Для данных разработки есть ещё один вариант:

## Пока форма ещё не устоялась

На раннем этапе разработки можно удалять устаревшие данные вместо поддержки
миграции для каждого экспериментального изменения:

<!-- shown: letting go of what nothing declares -->
```rust
let (store, report) = StoreBuilder::new(path)
    .rules(|r| r.on_undeclared(OnUndeclared::Drop))
    .migrate()?;

assert!(!report.has_drift());
```
<!-- /shown -->

`OnUndeclared::Drop` удаляет ключи под объявленными префиксами, которых
не объявляет ни одна текущая структура, и записывает текущую схему.
Переименованное поле начнёт с default: прежнее значение **удаляется, не переносится**.

Очистка выполняется после шагов миграции и пропускается при ошибке миграции.
Ключи вне объявленных префиксов не затрагиваются. Корень не очищается:
`as_root` объявляет конкретные поля, а не владение всеми корневыми данными.

Используйте эту политику только для одноразовых данных разработки.
По умолчанию `OnUndeclared::Keep` сохраняет необъявленные данные и сообщает о дрейфе.

## Как его прочитать

`MigrationReport::has_drift` показывает наличие дрейфа. В `component.nagging`
лежит `NaggingRecord` для каждой линии: префикс, `id`, изменённые пути,
их оценки и diff имён полей:

```rust
let (store, report) = StoreBuilder::new("./app.redb").migrate()?;

for record in report.components.iter().flat_map(|c| &c.nagging) {
    for moved in &record.moved {
        println!("{:?} {moved}", moved.verdict());
    }
}
```

Пути в записи отсчитываются от её префикса: `token`, не `app.token`.
Сам префикс тоже есть в записи.

## Как его показать

`build` и `migrate` записывают дрейф через `tracing`. Фича `diagnostics`
заменяет отдельные строки диагностикой в стиле предупреждений компилятора:

```toml
amethystate = { version = "0.27", features = ["diagnostics"] }
```

Например, выпуск, записавший данные, объявлял структуру так:

```rust
#[amethystate(prefix = "app", version = 2)]
pub struct Settings {
    #[amestate(default = None)]
    pub host: Option<String>,

    #[amestate(default = {})]
    pub port: ReactiveMap<String, u16>,

    #[amestate(default = String::new())]
    pub token: String,
}
```

Новый выпуск оставляет ту же версию, но меняет раскладку:

```rust
#[amethystate(prefix = "app", version = 2)]
pub struct Settings {
    #[amestate(default = "localhost".to_string())]
    pub host: String,

    #[amestate(default = 8080u16)]
    pub port: u16,
}
```

`token` удалён, `port` больше не карта, а `host` перестал быть необязательным.
Версия осталась `2`:

```
amethystate::drift

  ⚠ `app` holds a shape this build does not declare
  help: raise the struct's `version` and write a step for it, or declare the
        released places again

Warning:
  ⚠ `app.token` was declared before and is not now
  help: what an earlier build wrote there is under no declaration now

Warning:
  ⚠ `app.port` was written as Map and is declared as Field
  help: one value and a level of entries are not the same thing on disk

Advice:
  ☞ `app.host` may no longer hold nothing
  help: what was written there as nothing reads back as the declared default
```

Диагностика сначала показывает ломающие изменения, затем требующие проверки,
затем остальные. В исходных записях остаётся порядок сравнения.

`diagnostics` по умолчанию выключена и меняет только вывод. Проверка дрейфа
и `has_drift` работают без неё. `MigrationReport::drift` возвращает диагностики
для собственного отображения.

## Чего он не сравнивает

Проверка не анализирует типы листьев и внутреннее сериализованное представление.
Смена `u16` на `u32` не меняет занятый путь и сама по себе не считается дрейфом.
Несовместимое значение обнаружится при чтении поля через `on_unreadable`
и `disagreements()`. См. [Ошибки](/amethystate/ru/concepts/errors/).

## Что для этого нужно включить

Дрейф проверяется при каждом открытии через `build` или
[`migrate`](/amethystate/ru/store/opening/), даже без зарегистрированных шагов.

Только `migrate` выполняет шаги. Объявить функции с `#[migrate]`, а затем
вызвать `build` недостаточно: предупреждение о дрейфе не заменяет миграцию.
