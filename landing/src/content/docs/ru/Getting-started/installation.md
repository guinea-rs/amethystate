```toml
[dependencies]
amethystate = { version = "0.27", features = ["redb"] }
```

Включите движок хранения через фичу Cargo: по умолчанию ни один не включён.
Выбирайте его в крейте приложения. Библиотеки, которые только объявляют
состояние или предоставляют адаптер к фреймворку, могут оставить этот выбор
приложению.

## Выбор движка

Каждый store использует один движок. Фичи Cargo определяют, какие движки
доступны в сборке, а `StoreBuilder::backend` выбирает один из них при открытии.
Без явного выбора используется первый доступный движок в порядке, указанном ниже.

| feature | движок | где лежит |
| --- | --- | --- |
| `redb` | redb | файл `.redb` |
| `sqlite` | SQLite | файл `.db` |
| `json` | JSON | файл `.json` |
| `toml` | TOML | файл `.toml` |
| `ron` | RON | файл `.ron` |
| `localstorage` | localStorage браузера | ключи под `amethystate.<имя store>.` на странице |

**Текстовые движки пишут два файла**: документ с данными и файл `.meta`
с версиями схем, описаниями полей и состоянием миграции. Сам документ можно
прочитать отдельно, но без `.meta` store теряет историю схемы. При переносе
и резервном копировании сохраняйте оба файла. redb и SQLite хранят эти
метаданные внутри файла базы данных.

Форматы поддерживают разные значения. В
[сравнениях движков](/amethystate/ru/choosing/absent-or-null/) показаны результаты
записи одних и тех же значений каждым движком.

Сборка без движка всё равно компилируется, но store в ней не откроется:
`StoreBuilder::build` ответит `OpenStore::WouldNotOpen` и назовёт фичи, которые
надо включить.

Фича `memory` добавляет движок без файла. По умолчанию он не выбирается:
укажите его явно или используйте как запасной вариант, если файл не открылся.
См. [Открытие store](/amethystate/ru/store/opening/#или-работать-в-памяти).

### В браузере

Для браузерного приложения под `wasm32-unknown-unknown` включите `localstorage`.
Движок хранит по одному значению JSON на ключ в localStorage браузера; данные
видны в инструментах разработчика. Запись синхронная, без отложенного сброса,
а превышение квоты возвращается как ошибка записи. Изменения из других вкладок
приходят как внешние обновления. Этот движок открывается только на странице браузера.

```toml
amethystate = { version = "0.27", features = ["localstorage"] }
```

### Несколько движков сразу

Фичи Cargo складываются. Без явного выбора используется первый включённый
движок в порядке **redb, SQLite, JSON, TOML, RON, localStorage**. Если зависимость
включит `redb`, это может изменить движок вашего store.

Можно включить несколько движков, например для конвертера или набора тестов.
Выбирайте движок явно через `StoreBuilder::backend`, чтобы фичи зависимостей
не влияли на формат файла.

### SQLite

SQLite собирается из исходников, поэтому нужен C-тулчейн. Зато минимальную
версию SQLite выбирает библиотека, а не дистрибутив пользователя.

Это важно из-за требований возможностей SQLite к версии. Например,
`STRICT`-таблицам нужна SQLite 3.37. Более старая SQLite может сообщить
о повреждённой схеме, даже если файл цел и проблема только в версии.

```toml
amethystate = { version = "0.27", features = ["sqlite"] }
```
